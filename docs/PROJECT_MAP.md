# 编辑项目地图

项目地图网址是 `/projects/`。所有项目资料统一放在 `data/projects.yaml`，不需要修改页面模板或绘图代码。

## 添加一个项目

复制 `items` 中的一项，或按以下格式追加到文件末尾，保持缩进一致：

```yaml
  - id: my-new-project
    date: "2027-03-15"
    title: 我的新项目
    description: 用一句话介绍它做了什么。
    url: fun/my-new-project/
    tags: [JavaScript, 交互]
    related: [notes]
```

- `id`：唯一标识，只使用小写英文字母、数字和短横线。发布后尽量不改，其他项目的关联通过它查找。
- `date`：`YYYY-MM-DD` 格式。项目从早到晚自动排序，同一天按资料顺序排列。这里的日期不会控制草稿或定时发布，填写后就会出现在地图上。
- `title`、`description`：显示在项目卡片上的标题和简介。
- `url`：项目介绍或演示的地址。站内路径从博客根目录开始写，如 `fun/fireworks/`，不要加本机的 `127.0.0.1`。也可以填写完整的 `https://` 外部地址。页面会兼容 GitHub Pages 仓库子路径；请先创建实际目标页面。
- `tags`：技术或主题标签，第一项也会显示在卡片顶部。
- `related`：相关项目的 `id` 列表。没有关联时写 `[]`。只需一方填写，双方悬停时都会突出同一条线；重复的双向关系不会画两遍。关联不存在的 ID 或自身、重复 ID 会在构建时明确报错。

## 年份与日期

`start_year` 决定最早展示的年份，当前为 2023。页面自动展示到当前年份或最新项目年份；新增更早的项目也会自动补上更早的年份。没有项目的年份标注“留待补充”，年份之间用虚线连接。

当前四个项目都使用 2026-09-27，这是迁移到博客的收录日期，并非确认过的完成日期。因此页面左栏标注“收录时间”。如果想按实际完成日期展示，请逐项修改 `date`，再将 `date_label` 改为“完成时间”。

## 便签墙与交互

页面里的大画布按年份从上往下排列，同一年项目默认按日期从左往右排列。不同年份之间、同年相邻项目之间，以及 `related` 指定的项目之间，均有虚线连接。

- **平移**：拖动画布空白处；鼠标或触控板滚动也可以平移。
- **缩放**：使用工具栏的 `−` / `+`，或 Ctrl / ⌘ 加滚轮；触屏可以双指缩放。缩放以鼠标或双指中心为基准。
- **移动便签**：拖动便签顶部抓手或没有链接的正文区域，连线会跟着便签实时移动。标题链接仍用于进入项目页面。
- **查看关联**：悬停或聚焦便签会抬起便签与关联线，其他便签变暗。点击“关联”固定高亮，再次点击取消固定；Escape 或点击画布空白处可以清除高亮。
- **快速定位**：顶部年份按钮定位到该年份；“全览”缩放到全图。“恢复排列”将所有便签恢复为时间顺序，也提供“撤销恢复”。
- **全屏**：右上角四角展开图标进入全屏，按钮在全屏时仍位于右上角。再次点击或按 Esc 退出，恢复进入前的缩放与视野。浏览器不支持或不允许原生全屏时，自动使用铺满网页窗口的模式。全屏不会重置便签位置。
- **键盘操作**：Tab 聚焦便签抓手后，用方向键移动便签，Shift 加方向键可快速移动。聚焦画布时，方向键平移，`+` / `-` 缩放，`0` 全览。

## 位置保存

拖动和键盘移动结束后，位置自动保存在**当前浏览器的 localStorage**；刷新或重新打开同一网址会恢复。它不会写回项目资料、Git 仓库或同步到其他设备。访问不同域名、端口或 GitHub Pages 路径时，也可能使用独立的存储。浏览器清除网站数据后会恢复默认排列。

保存的是各项目相对于自动排列位置的偏移，使用 `id` 和 `date` 识别。新增项目会自动加入对应年份；修改项目日期后，该便签按新日期重新排列。拖动便签本身不会修改项目日期或年份归属。窗口位置和缩放不保存，重新打开会先展示默认视野，手机上可以横向拖动查看右侧项目。

浏览器禁止存储时，仍可拖动和缩放，页面会提示本次位置无法保存。

## 预览

运行 `.tools/hugo server -D` 后，保存 `data/projects.yaml` 即可预览。新增年份和关联无需手动计算坐标。深浅色跟随全站设置，便签会相应调整配色。

没有 JavaScript 时，年份、日期、项目介绍和链接仍可在可滚动的区域内阅读；拖动、缩放、位置保存和连线高亮需要 JavaScript。

## 实现位置

- `data/projects.yaml`：项目资料，日常只需编辑这里。
- `layouts/projects.html`：按日期组织年份和卡片，并检查 ID 与关联。
- `assets/css/projects.css`：地图排版和悬停效果。
- `assets/js/projects.js`：绘制虚线，处理平移、缩放、拖动、键盘、触摸和本地位置保存。
